# Community Food Rescue Tracker

## Project Overview
A menu-driven Python terminal application for recording surplus food donations,
viewing available food, searching food records, and tracking collections.

## Problem
Surplus food can be difficult to track and connect with people who can collect it.
This prototype provides a simple way to record and manage available donations.

## Features
- Add surplus food with quantity, unit, condition, location, and expiry date.
- View food that is available for collection.
- Update a food record when it has been collected.
- Search food records by name or location.

## Technologies
- Python
- SQLite
- Object-oriented programming (OOP)

## Run the Application
Open the project in Visual Studio Code and run main.py using the Run Python File button.

## Tests
Run test_app.py using VS Code's Run Python File button, or use the Testing panel
after discovering tests with the Python extension.
